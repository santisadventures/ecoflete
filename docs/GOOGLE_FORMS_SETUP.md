# Formularios

Usar tres formularios permanentes:

- `Ofrecer un flete`
- `Buscar un flete`
- `Solicitar contacto`

Los formularios de publicación recopilan datos privados. Ninguna respuesta se publica automáticamente.

El formulario de interés debería pedír nombre, WhatsApp, email opcional, ID de publicación y mensaje opcional. La URL se configura en `js/config.js` como `INTEREST_FORM_URL`.
